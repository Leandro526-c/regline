Regline 4.3 · Windows, Mac et Linux

Regline est construit avec des logiciels libres de grande qualité, utilisés par les scientifiques du monde entier. Merci à leurs auteurs.

En bref
  • Ces logiciels gardent leur propre licence. Le contrat de licence de Regline ne limite aucun des droits qu'elles te donnent.
  • Les textes complets sont dans l'app (menu Aide → Licences et logiciels libres) et, sous Windows, dans le dossier licences-tierces de l'application.
  • Regline lui-même n'est pas un logiciel libre : il est gratuit pour les élèves, les étudiants et l'usage personnel (voir les conditions d'utilisation).

Qt et la LGPL : tes droits

Les bibliothèques Qt sont livrées comme fichiers séparés dans le dossier de l'application (par exemple les fichiers Qt6*.dll sous Windows). La licence GNU LGPL v3 te permet de les remplacer par une version modifiée de Qt, compatible, et de faire l'ingénierie inverse nécessaire pour déboguer ces modifications. Le contrat de licence de Regline ne l'interdit pas. Pour remplacer facilement ces fichiers, utilise l'installateur téléchargé sur regline.ch plutôt que la version du Microsoft Store, dont Windows protège le dossier.

Le code source de Qt et de Qt for Python est disponible sur download.qt.io et code.qt.io. Sur simple demande à contact@regline.ch, je t'envoie aussi une copie du code source exact des versions de Qt utilisées, sans frais autres que ceux de l'envoi, pendant au moins trois ans après la dernière distribution de la version concernée de Regline.

Le module vidéo : FFmpeg

Pour lire les images d'une vidéo, Regline utilise FFmpeg 7.1, sous licence GNU LGPL 2.1 ou plus. C'est un programme séparé, non modifié, compilé sans aucun composant GPL ni « nonfree ». Regline le lance pour lui demander les images : FFmpeg ne fait pas partie de Regline et garde sa propre licence.

  • Version téléchargée sur regline.ch : FFmpeg n'est pas dans l'installateur. La première fois que tu ouvres une vidéo, Regline te propose de télécharger le module vidéo depuis la page GitHub de Regline, et vérifie son empreinte SHA-256 avant de l'installer. Si FFmpeg est déjà installé sur ton ordinateur, Regline l'utilise et ne télécharge rien.
  • Version Microsoft Store : FFmpeg est inclus dès l'installation, rien n'est téléchargé.
  • Le texte de sa licence est dans le dossier du module et dans la fenêtre Licences de l'app. Code source exact de la version distribuée : ffmpeg-7.1.tar.xz. Informations juridiques du projet : ffmpeg.org/legal.html.

FFmpeg est une marque de Fabrice Bellard, créateur du projet FFmpeg. Regline n'est ni affilié au projet FFmpeg ni approuvé par lui.

Pilotes des appareils de mesure

Pour les appareils de labo (VISA) et les cartes National Instruments, Regline utilise les pilotes déjà installés sur ton ordinateur, par exemple NI-VISA ou NI-DAQmx. Ils ne sont pas livrés avec Regline et restent soumis aux conditions de leur fabricant.
